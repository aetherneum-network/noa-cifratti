# S02 - five planted secrets among twelve decoys

*Company (synthetic): Studio Cartografico Lunaria. Lessons covered: L2.* **Failure reproduced.** A small service tree holds five inert secrets (vendor token, webhook secret, quoted password, password in a connection URI, armoured key block) and twelve things that only look like secrets (hashes, a UUID, a public identifier, placeholders, a variable reference, a data URI, plain Base64 text, a label under a secret-looking key). **Pass criterion.** 5 of 5 planted secrets are found at the labelled path and line with the labelled fingerprint; no decoy is reported as a secret; at most one decoy is sent to review (the label under a secret-looking key, which a weak password would resemble). The tree is committed under `input/tree/`; `input/labels.json` lists plants and decoys without any value. Run `python scenarios/S02/check.py` from the repository root (or `python check.py` in this folder): it compares the output with `expected/` byte for byte and then asserts the criterion in code.
