# S09 - a secret rule is narrowed

*Company (synthetic): Cooperativa Tessile Arvale. Lessons covered: L7.* **Failure reproduced.** A rule patch restricts the unquoted `KEY=value` rule to environment files. **Pass criterion.** `noascan rules-diff` scans with the current and the patched rules and reports exactly which findings change: the two unquoted passwords outside environment files (`deploy/values.yml`, `scripts/backup.sh`) are lost, nothing is gained, nothing moves to another rule; the digests of the rule file before and after are in the report, together with the rule's own examples that the patch stops matching. The patch is committed as `input/patch.json`; the repository is written under `build/`. Run `python scenarios/S09/check.py` from the repository root (or `python check.py` in this folder): it compares the output with `expected/` byte for byte and then asserts the criterion in code.
